# Analysis Outputs

This folder contains the exported visualizations and results generated during the RavenStack SaaS Retention Analysis project.

### Files

- **cohort_retention_heatmap.png** – A heatmap visualizing monthly customer retention across signup cohorts from January 2023 to December 2024.

### Purpose

These outputs help communicate customer retention patterns, compare cohort performance, and identify areas that may require further investigation.

The visualizations are generated using Python and are intended to support business analysis and decision-making.
