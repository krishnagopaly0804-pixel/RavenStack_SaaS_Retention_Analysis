# Notebooks

This folder contains Jupyter notebooks used for Python-based analysis in the RavenStack SaaS Retention Analysis project.

### Files

- **03_cohorts.ipynb** – Performs cohort-based customer retention analysis, including data preparation, retention calculations, validation checks, visualizations, and business insights.
- **cohort_retention_output.csv** – Contains the calculated monthly cohort retention results exported from the notebook.

### Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

The notebooks support the analysis and interpretation of customer retention trends across different signup cohorts.
